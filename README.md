# 智慧教育课程连续播放

这是一个适用于 Chromium 浏览器（Chrome、Edge）的 Manifest V3 扩展，用于辅助播放国家智慧教育公共服务平台**教师发展中心**的课程视频。扩展会尝试在视频结束后选择下一节，也提供目录诊断和播放速度测试。安装时无需构建或第三方依赖。

> **关于倍速和学时：** 使用本扩展加速播放**无法绕过平台的倍速检测**，也不能保证获得学时。“页面读取的倍速最多 2×”仅改变一处页面脚本可读的属性值，平台仍可能根据视频时间、播放事件、服务端记录等信号识别加速或暂停学习。页面继续播放、弹窗被关闭，均不代表平台认可该段学习时间。请以平台显示的学习状态和学时为准，并遵守课程要求。

## 适用范围

- 页面：`https://www.smartedu.cn/jiaoshi/` 下的教师发展中心课程页，通常带有 `courseId`，例如 `courseIndex`、`courseDetail`。
- 浏览器：支持加载 Manifest V3 扩展的 Chrome 或 Edge。
- 其他子站、不同域名或跨域 iframe 内的播放器尚未适配。平台页面结构变化时，目录识别可能失效。**使用自动连播前，建议先用“预览下一节”核对目标。**

## 安装与更新

1. 下载本仓库的 ZIP 并解压，或克隆仓库。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `smartedu-autoplay` 文件夹。
4. 自行登录平台，打开教师发展中心课程的视频播放页，再点击扩展图标。

更新文件后，在扩展管理页点击本扩展的“重新加载”，然后刷新课程页。扩展不会读取或保存你的账号密码。

## 使用

| 控件 | 作用 |
| --- | --- |
| 开始 / 继续 | 开启连播，尝试播放当前视频；设置会保存，对适用的课程页通用。 |
| 暂停 / 停止 | 关闭连播并暂停当前视频。当前两个按钮的播放控制效果相同。 |
| 预览下一节 | 只显示预计的下一节，或显示需要先展开的大标题；不切换视频。 |
| 测试切换下一节（立即切换） | 立即点击识别到的目录项，会跳过当前视频剩余部分；仅用于手动核对目录识别。 |
| 扩展倍速 | 选择“跟随平台”或 1×～16×。扩展尝试直接设置视频实际速度，平台可能重置或拒绝该速度。 |
| 测试：页面读取的倍速最多 2× | 默认关闭。开启时，页面脚本通过普通 `video.playbackRate` 读取到的值最高为 2×，实际播放速度不因此降低；弹窗诊断行显示扩展读取的实际速度。此功能仅供兼容性测试，**无法绕过平台倍速检测**。 |

连播开启后，关闭弹窗、点击页面其他位置、切换适用课程或最小化浏览器窗口，不会自行关闭连播开关。视频结束时扩展会尝试选择下一节；在能识别目录结构时，也会跨大标题展开下一组，最多连续展开三层。无法确定下一节时，扩展会等待并在弹窗中报告状态，不会盲目点击。

扩展会尝试恢复非手动暂停：30 秒内最多重试三次，之后等待约 30 秒再检查。手动暂停、答题和验证会让播放等待处理。浏览器可能阻止自动播放，届时需在网页上手动点击一次播放。窗口最小化时后台约每 30 秒检查一次；浏览器或系统休眠、标签页被冻结或丢弃时，无法保证持续播放。

扩展可自动确认识别到的学时说明弹窗，但这不会改变平台的学时规则。平台提示检测到倍速播放时，普通模式会关闭扩展倍速并等待手动处理；启用“页面读取最多 2×”测试时会有限次确认提示并重试。**重试成功也不代表该段播放计入学时。**

选择“跟随平台”会尝试恢复启用扩展倍速前的速度。“停止”只关闭连播控制，不自动清除扩展倍速设置。测试结束后，请手动改回“跟随平台”并关闭 2× 读取测试。

## 排查问题

- **显示“未识别到下一节”**：先确认当前视频行在右侧目录中高亮；展开相关大标题后再次预览。部分课程目录结构不同，需要提供课程 URL、目录截图及弹窗状态才能进一步适配。
- **显示“播放器：未检测到”**：先在页面打开一节视频并刷新；若播放器处于跨域 iframe，扩展可能无法控制。
- **不能自动播放或最小化后停止**：先在页面手动播放一次，检查是否有答题、验证或平台提示；浏览器冻结、丢弃标签页或设备休眠时后台检查不会可靠执行。
- **选择了倍速但速度没变**：查看弹窗诊断行。平台或浏览器可能覆盖设置；收到平台倍速警告时，以平台状态为准。
- **更新后仍是旧行为**：在扩展管理页重新加载扩展，然后刷新课程页。

## 本地测试

安装 Node.js 后，在本目录运行：

```sh
npm test
npm run check
```

测试使用 Node.js 内置模块，不需要执行 `npm install`。这些测试覆盖部分目录识别、后台检查和倍速属性行为；**不能代替在真实课程页的手动验证**。

## 权限与数据

- `https://www.smartedu.cn/*`：向平台页面注入测试脚本；主要控制逻辑只在 `/jiaoshi/` 页面运行。
- `storage`：保存连播开关；倍速和 2× 读取测试保存在当前标签页的会话存储中。
- `alarms`：在连播开启期间安排后台定期检查。
- `activeTab`：让弹窗与当前课程标签页交互。

扩展源码没有向自有服务器发送请求，也不采集账号密码；浏览器访问平台时，平台自身的网络请求仍照常发生。发布前请自行审阅源码和权限。
